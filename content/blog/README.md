# Blog — friction minimale

1. Créer un fichier `mon-titre.md` dans ce dossier
2. Frontmatter obligatoire :

```
---
title: Mon titre
date: 2026-11-24
excerpt: Une phrase
---
```

3. Corps en Markdown simple (`##`, `- `, `**gras**`, `[lien](/contact)`)
4. Commit + push → Vercel rebuild → article en ligne

Pas de CMS. Pas de base de données.
